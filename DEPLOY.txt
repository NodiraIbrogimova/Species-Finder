Species Finder — self-deployment with GitHub Pages

1. Extract this ZIP on your computer.
2. Sign in to github.com. Create a PUBLIC repository called species-finder. Enable Add a README so the main branch exists.
3. In the repository, select Add file > Upload files.
4. Drag the extracted CONTENTS into the upload area, including the assets folder. Do not upload the ZIP or its containing folder. index.html must be at the repository root.
5. Commit changes to main.
6. Open Settings > Pages > Build and deployment.
7. Set Source to Deploy from a branch, Branch to main, Folder to / (root), and Save.
8. Check Actions for the deployment status, then Settings > Pages for your website link.
9. Test all three languages, the five locations, Show Uzbekistan and Download species data.

Your URL will normally be https://YOUR-USERNAME.github.io/species-finder/ .

The prototype is static HTML, CSS, JavaScript and JSON. No terminal, build command, database or API key is needed. It does not yet identify photos or edit a shared database. The background map needs an internet connection.

To update: edit a file in the repository and commit the change. Pages rebuilds it.

Public repositories expose their files. This package contains no API keys. The photograph is from your supplied document; confirm permission before publishing it publicly or replace assets/snow-leopard.jpg with an image you may publish. The provided coordinates remain unverified.

Free hosting and open source are different: GitHub Pages provides hosting; a code license defines reuse permissions. This package does not assign a license to your project. Leaflet retains its own license in assets/LEAFLET-LICENSE.txt.
